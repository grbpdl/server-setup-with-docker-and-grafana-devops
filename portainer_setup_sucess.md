## Troubleshooting

### Can't access the URL
1. Verify DNS: `dig prod.container.infocarenepal.com`
2. Check containers: `docker ps | grep -E "(traefik|portainer)"`
3. Check Traefik logs: `docker logs api_gateway-main-1 | grep prod.container`

### SSL Certificate Issues
- Check Traefik logs for ACME errors
- Verify DNS TXT records for Let's Encrypt challenge
- Wait 5-10 minutes for certificate propagation

### Portainer won't start
- Check: `docker logs portainer`
- Verify Docker socket exists: `ls -la /var/run/docker.sock`
- Check if port 9000 is in use: `netstat -tulpn | grep 9000`
