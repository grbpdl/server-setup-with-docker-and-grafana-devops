# Portainer Setup Guide

## Current Status ✅
- Portainer container is running
- Configured to work with Traefik as reverse proxy
- SSL certificates will be auto-generated by Let's Encrypt

## What You Need to Do

### 1. Add DNS Record
Go to **DigitalOcean DNS Management** and add a new A record:
- **Name**: `portainer`
- **Type**: A Record
- **Value**: Your server's IP address
- **TTL**: 3600 (or default)

### 2. Access Portainer
Once DNS propagates (5-10 minutes), you can access Portainer at:
- **URL**: https://portainer.infocarenepal.com

### 3. Initial Setup
On first access, you'll need to:
1. Create an admin user (username and password)
2. Connect to the Docker environment
3. Select "Local" for the local Docker connection

## Current Configuration

### Domain
- `portainer.infocarenepal.com`

### Ports
- **9443**: HTTPS (internal Portainer)
- **9000**: HTTP (internal Portainer)
- Traefik proxies HTTPS traffic from port 443 to port 9000

### Volumes
- `data`: Stores Portainer database and configuration

### Docker Compose
- Location: `/root/server-setup-with-docker-and-grafana-devops/portainer/`
- `.env` file contains environment variables
- Network: `production_network` (shared with Traefik)

## Troubleshooting

### Can't access portainer.infocarenepal.com
1. Verify DNS record is added in DigitalOcean
2. Wait 5-10 minutes for DNS propagation
3. Check DNS resolution: `nslookup portainer.infocarenepal.com 8.8.8.8`

### SSL Certificate Issues
1. Check Traefik logs: `docker logs api_gateway-main-1`
2. Verify domain is resolving: `dig portainer.infocarenepal.com`

### Portainer won't start
1. Check if port 9443 is already in use: `netstat -tulpn | grep 9443`
2. View logs: `docker logs portainer`
3. Verify Docker socket is accessible: `ls -la /var/run/docker.sock`
